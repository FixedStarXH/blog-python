对照 Go 的 `controller/article.go`、`service/article.go`、`dao/article.go`、`utils/html2md.go` 和前端调用，按接口记录 Python 的可观察行为。

| 接口 | 调用方可以依赖的行为 | 已知差异 |
| --- | --- | --- |
| `GET /api/articles` | 支持关键词、分类、作者、标签、热门排序和分页。精选模式只使用精选标记和种子，同一数据集与种子下可稳定翻页。响应含 `list/total/page/pageSize`。 | 搜索额外覆盖摘要。列表仅收录公开文章，私密正文也不参与关键词匹配。分页参数越界返回 422。精选的具体排列可以与 Go 不同。 |
| `GET /api/articles/{id}` | 公开文章返回经过清理的 HTML 和 `needPassword=false`。已发布的私密文章返回标题、ID 和锁定标记。 | 锁定时省略正文及其他详情字段。公开响应省略用户敏感字段和编辑专用字段。 |
| `POST /api/articles/{id}/unlock` | 请求体为非空字符串 `password`。私密文章验证通过后返回详情，公开文章直接返回详情。 | 错误口令返回 403，文章不可见返回 404，无效请求体返回 422。 |

## 账号和投稿接口兼容（第一批）

注册、登录、刷新、退出、个人资料、修改密码及个人投稿已对照 Go 控制器、服务和现有前端。账号支持用户名或邮箱登录，修改密码后撤销已签发的 refresh token，并发注册撞上相同用户名或邮箱时返回 409。个人资料更新返回与读取一致的用户字段。

投稿创建、详情、列表、编辑和删除使用作者身份校验。创建为待审核，草稿或被驳回文章修改后进入待审核，已发布文章修改后直接更新。列表的负数状态值表示全部状态。投稿不能选用已软删除分类，私密密码仍按本项目约定使用哈希存储并通过 `clearPassword` 显式清除。

Go 对部分业务错误返回 HTTP 200，Python 返回相应的 HTTP 状态码。Python 注册成功返回 201，修改密码至少六位，个人接口访问他人的文章返回 404。注册时校验邮箱格式，不进行 DNS 或邮箱归属验证。两套服务的逐项动态对照尚未进行。

## 评论与审核接口兼容

对照 Go 评论控制器、服务、DAO 及文章页和后台评论页。游客和登录用户均可提交评论、回复已通过的同文章评论。新评论默认为待审核，后台通过后才公开。后台支持按状态筛选、通过、驳回、删除和批量操作。公开及后台列表参数限制在有效分页范围内，创建时间相同时按 ID 排序。

文章页按需加载更多评论，并在父评论不可见时展示仍然公开的回复。评论 Markdown 输出会移除不安全的链接和资源协议。评论点赞按访客 IP 去重，同一访客并发请求只计一次，更新与去重记录在同一数据库事务中。

已在 SQLite 与隔离 MySQL/Redis 上验证评论审核和小规模并发点赞，并用浏览器验证提交、审核、加载更多和链接过滤。Go 原版默认直接公开评论且点赞无服务端去重，Python 按本项目需求保留审核和 IP 去重。超过一页的浏览器验证使用模拟评论数据，尚未进行大规模评论和长期并发压测。

## 投稿与后台文章管理

作者投稿进入待审核，编辑驳回需填写原因，作者修改草稿或被驳回文章后重新进入待审核。审核通过时，未来发布时间进入排期，否则立即发布。作者编辑排期文章时，未传发布时间会保留原排期，明确清空发布时间会转为待审核。后台创建或编辑排期文章必须提供发布时间。

审核通过和驳回通过数据库条件更新保证同一条待审文章的并发审核只成功一次。定时任务只发布执行更新时仍然到期、处于排期状态且未删除的文章，提交成功后使公开缓存版本失效。Redis 不可用时缓存失效依赖恢复或缓存过期。后台文章写入拒绝已删除分类，批量操作校验文章 ID 和操作类型，软删除与恢复保留文章数据。

SQLite 回归覆盖投稿、驳回重提、排期修改、批量操作、回收站、权限和失败回滚，隔离 MySQL/Redis 验证并发审核、到期发布和缓存刷新。Go 原版审核和批量状态操作的部分约束与 Python 不同，本项目将已记录的状态和 HTTP 错误规则作为实现。多实例长期竞态、AI 索引重建和完整 Go 动态对照仍列在后续步骤。

## 分类、标签和专栏

分类和标签的创建、修改、删除具有输入校验和重复名称检测。公开标签返回公开可见文章数量，后台分类和标签统计未删除文章。标签删除时事务清理文章关联，文章写入和分类、标签、专栏删除在关联行上互斥，避免并发提交后引用已删除对象。

分类或专栏仍被文章引用时拒绝删除，回收站文章也计入引用，以便恢复时保留关系。需要删除时，可先恢复文章并改用其他分类或移除专栏。已有数据库中在本次改动前形成的失效关联不会自动修复。分类和标签软删除后其名称仍被现有唯一约束占用。

个人中心提供专栏创建、编辑、关闭和删除，投稿页可选择自己的专栏。文章编辑省略专栏字段会保留已有关系。标签墙会读取筛选结果的所有分页并按文章 ID 去重，目前结果较多时会发起多次请求。Go 原项目含专栏模型但没有对应的专栏管理路由，本项目按需求补充。

SQLite 和隔离 MySQL 验证了分类删除与文章创建的小规模并发、引用检查和作者权限。浏览器验证了专栏管理、投稿选择，以及使用模拟数据的多页标签筛选。大规模并发及完整 Go 动态接口对照仍在后续步骤。

## 用户与权限管理

后台新增用户管理页面，管理员可按用户名或邮箱查找、按角色筛选并分页，直接调整其他账号的角色及禁用状态。编辑可管理文章，但不能查看或修改用户。管理员不能修改自己的角色或状态；缺失、无效或越界参数由请求模型拒绝，已删除或不存在的目标返回 404。

角色变更会在下一次请求按数据库中的最新角色生效。禁用账号会在同一事务中撤销该账号尚未撤销的 refresh token；后续的旧 access token 请求、登录和 refresh 均被拒绝。登录、refresh 轮换、登出、修改密码和禁用账号按用户行锁串行化，避免并发刷新或登录在禁用提交后留下可用 refresh token。重新启用账号不会恢复旧 refresh token，须重新登录。SQLite 回归覆盖筛选、权限、参数和状态；隔离 MySQL 验证了刷新与禁用同时请求的结果，浏览器验证用户管理页面操作。

登出和修改密码会撤销 refresh token；已经签发的无状态 access token 仍可用到过期（默认 2 小时）。禁用账号和角色变更会在每次请求查库时立即生效。已开始执行的请求可能完成原有操作，后续安全验收继续检查这一边界。完整 Go 动态接口对照仍在第 8 步。

## 图库与文件上传

登录用户可通过 `/api/upload` 上传，编辑和管理员可使用后台上传、分页图库和删除。只接受 jpg/jpeg/png/gif/webp，文件不得超过 5 MiB，文件头、解码格式和完整性都经过检查，并限制图片像素数为 2500 万。超出大小或尺寸返回 413，格式错误或内容损坏返回 415。原始文件名仅用于图库展示且清理目录字符，磁盘路径由随机文件名生成，不接受客户端路径。

上传先写文件再提交元数据；数据库提交失败时删除新文件。删除先验证本地路径并把文件移到上传卷内的临时位置，数据库提交失败时移回原路径；提交成功后清理临时文件。旧数据中的 `/uploads/年/月/文件` 路径仍可删除，文件已缺失时可清除元数据；越过上传目录或远程 URL 的记录拒绝删除。强制断电或进程崩溃等跨文件系统和数据库事务的中断仍可能留下孤儿文件或 `.deleting-*` 暂存文件，需要人工核对后清理，不会自动删除未登记的历史文件。

图库页面支持点击、键盘和拖放上传，展示原始文件名、大小、复制链接、删除及缺失文件提示；删除当前页最后一张图后分页会回到有效页。SQLite 验证了五种格式、大小和内容伪装、权限、分页、路径安全及数据库失败后的文件恢复；隔离 Compose 环境验证了上传卷和 MySQL 记录在应用重启后持久存在，浏览器验证上传和删除。上传卷的长期备份与旧 Go 图片整体迁移仍属于第 14、15 步。

本轮改动前已写入的 Python 图片记录可能只保存了随机展示名，现有元数据无法还原当时的原始文件名；新上传图片会正确保存原始展示名。

本文记录 Python 代码相对于 [需求规格说明](需求规格说明.md) 的实际落地状态。Go 项目和原前端仍是行为参照；本文件不代表接口联调或生产验收已经完成。

## 已实现的主干

- FastAPI 应用装配、统一 JSON 信封、401/403 权限分层、请求日志、安全响应头、健康与就绪探针、API 未知路径 JSON 404。
- SQLAlchemy 2 ORM、MySQL/SQLite Session、Alembic 初始迁移、幂等分类/站点/管理员种子数据；启动不执行 `create_all`。
- 用户注册/登录、access/refresh token、refresh 单次条件更新轮换、退出、资料/改密、角色保护和禁用时撤销 refresh token。
- 公开文章列表/详情/私密解锁、浏览与点赞去重、导出、归档、导航、评论、分类/标签；个人投稿与软删除；编辑审核、管理和回收站过滤。
- 管理用户、评论、分类、标签、设置、友链、图库、仪表盘、操作审计；图片扩展名、文件头和 5 MiB 大小校验。
- RSS、Sitemap、保留的 React/Vite 多页前端、Compose MySQL/Redis/上传卷、定时发布任务。
- OpenAI 兼容 Chat/Embedding 客户端，文章切块、索引替换、公开语料过滤、Top-5 向量检索和 SSE 输出；AI 路由与通用路由分离。
- Redis 限流、公开 GET 短缓存及写操作版本失效；Redis 不可用时限流退化到进程内计数，核心请求继续处理。AI 每日 100 次额度仅在 Redis 可用时跨请求计数。

## 公开文章接口兼容清单（第一批）

对照 Go 的 `controller/article.go`、`service/article.go`、`dao/article.go`、`utils/html2md.go` 和前端调用，按接口记录 Python 的可观察行为。

| 接口 | 调用方可以依赖的行为 | 已知差异 |
| --- | --- | --- |
| `GET /api/articles` | 支持关键词、分类、作者、标签、热门排序和分页。精选模式只使用精选标记和种子，同一数据集与种子下可稳定翻页。响应含 `list/total/page/pageSize`。 | 搜索额外覆盖摘要。列表仅收录公开文章，私密正文也不参与关键词匹配。分页参数越界返回 422。精选的具体排列可以与 Go 不同。 |
| `GET /api/articles/{id}` | 公开文章返回经过清理的 HTML 和 `needPassword=false`。已发布的私密文章返回标题、ID 和锁定标记。 | 锁定时省略正文及其他详情字段。公开响应省略用户敏感字段和编辑专用字段。 |
| `POST /api/articles/{id}/unlock` | 请求体为非空字符串 `password`。私密文章验证通过后返回详情，公开文章直接返回详情。 | 错误口令返回 403，文章不可见返回 404，无效请求体返回 422。 |
| `GET /api/articles/{id}/export` | 省略格式或指定 `format=md` 时返回 JSON，正文保留 Markdown 标题、强调、链接、列表和代码块。不支持的格式返回 400。 | 转换前清理 HTML，具体空白和标记排版可与 Go 不同。私密文章和不可见文章返回 404。 |

Go 的业务失败通常返回 HTTP 200 和 JSON `code=400`。Python 按本项目的统一接口约定返回对应的 HTTP 错误状态。以上为源码对照与 Python 端回归范围。
